# Pointille

Инструмент для создателей дрон-шоу. Загрузите 3D-модель (например, сгенерированную ИИ), укажите
количество дронов — Pointille равномерно расставит ровно столько точек по её поверхности и возьмёт
для каждой цвет текстуры в том месте, где она стоит.

**Исходная модель не изменяется**: сетка, UV, материалы и текстуры остаются как были. Точки для
дронов — это отдельный объект поверх модели.

| | |
|---|---|
| Точное количество | Вы задаёте N — получаете ровно N дронов |
| Равномерно | Blue-noise отбор + выравнивание: минимальная дистанция ≈ 0.8 от идеальной сотовой сетки |
| Цвет из текстуры | Цвет под дроном или средний цвет его участка поверхности |
| Видно ночью | Тёмные места модели светятся тускло, но не гаснут (*Мин. яркость*) |
| Фасад | Только сторона, которую видят зрители (с учётом перекрытий) |
| Обводка | Часть дронов — точно на силуэте, рельефе (глаза, рот, складки), рёбрах, краях и границах цветов, гуще заливки: фигура и картинка читаются чётче |
| Углы → линии → заливка | Blender: сначала углы на мин. дистанции, потом линии реже, потом редкая сетка (соты или квадраты); лимит вершин вместо точного числа — остаток в резерве; у каждого объекта свой режим (контур, рисунок по цветам, заливка) |
| Безопасность | Показ мин./средней дистанции, масштабирование под мин. дистанцию или высоту фигуры |
| Где работает | Веб-версия (любая ОС, без установки), аддон Blender, командная строка |
| Результат | GLB (модель + дроны), CSV (м, Z вверх), PLY — открываются в Blender, Cinema 4D, Houdini, 3ds Max, Maya, Unreal, Unity, Skybrush |

## Веб-версия

Откройте `web/index.html` через любой локальный сервер:

```bash
npx http-server web -p 8080        # или: python -m http.server -d web 8080
```

и перейдите на <http://localhost:8080>. После включения GitHub Pages (Settings → Pages → Source:
GitHub Actions) страница публикуется автоматически из ветки `main`.

1. Перетащите модель: **GLB** / **GLTF** (+ .bin и текстуры) / **OBJ** (+ .mtl и текстуры) / **FBX**.
   Сжатые Draco и Meshopt GLB поддерживаются.
2. Задайте **количество дронов** — расстановка пересчитывается автоматически.
3. Выберите **область** (вся поверхность / фасад), **цвет** и при необходимости **масштаб**.
4. Скачайте результат:
   - **GLB: модель + дроны** (для GLB на входе) — исходный файл сохранён байт в байт, добавлен узел
     `Pointille_Drones` (точки с цветом `COLOR_0`). Если выбран масштаб, всё помещается под узел
     `Pointille_Root` с нужным масштабом;
   - **CSV** — `id,x,y,z,r,g,b,hex`, метры, Z вверх (как в Blender и большинстве программ для шоу);
   - **PLY** — облако точек с цветами в системе координат модели.

Переключатель «Только дроны» показывает, как фигура будет выглядеть ночью.

## Аддон для Blender

Blender 4.2+ (как Extension) и 3.6–4.1 (как обычный аддон).

```bash
python tools/build_blender_addon.py     # → dist/pointille_blender-0.18.2.zip
```

Blender → *Edit → Preferences → Add-ons → Install from Disk…* → выберите zip (или скачайте
его из артефактов GitHub Actions).

В 3D-виде нажмите **N** → вкладка **Pointille**:

1. Выделите модель (можно несколько мешей — они считаются вместе).
2. Укажите **Вершин**, **Область**, **Цвет**, **Безопасность** → **Распределить вершины**.
   Параметры можно менять после запуска в панели *Adjust Last Operation* (F9) — результат
   пересчитывается.
3. Появится объект `<модель>_points` — меш **только из вершин** (по одной на будущего дрона) с
   атрибутом цвета `drone_color`. Больше на модель ничего не ставится. Объект привязан к модели и
   двигается вместе с ней; его можно сразу использовать в Skybrush Studio как формацию из вершин:
   все вершины уже в группе вершин `Pointille`, и она записана в *Object Data → Drone Show → Name of
   Formation Vertex Group* (Edit Mode, Assign и *Use selected* не нужны).
4. В блоке «Результат»: мин. и средняя дистанция, габариты, **Объект на вершинах**, кнопки
   **Масштабировать** и **Экспорт CSV**.

### Количество «Не больше» (по умолчанию, с 0.12)

Вершины встают так, как рисуют фигуру: **сначала углы** (там, где линии сходятся или резко
ломаются, — на мин. дистанции друг от друга, шаг растёт вдоль линии от угла), **потом линии**
(силуэт, рельеф, рёбра, края, границы цветов — шаг *Шаг линий* × мин. дистанция, по умолчанию
×1.5) и **потом редкая заливка** остальной поверхности (*Шаг заливки*, по умолчанию ×3). Заливка
— **треугольная** или **квадратная сетка**, ровная так, как её видят зрители, или прежняя
равномерная.

**Макс. вершин** — лимит, а не цель: фигура берёт столько, сколько ей нужно при этих шагах.
Если нужно больше лимита, все шаги растут в одно и то же число раз, пока фигура не влезет. В
«Результате» видно, сколько создано, сколько осталось в резерве (для других объектов или
анимации), сколько ушло на углы, линии и заливку.

Если выделено несколько объектов, у каждого свой **режим**:

| Режим | Что получает объект |
|---|---|
| Контур + заливка | углы, линии и редкую заливку |
| Только контур | только углы и линии (скала под тигром) |
| Рисунок по цветам | линии и заливку только выбранных цветов (чёрные полосы тигра без оранжевой шерсти) |
| Только заливка | только сетку или равномерную заливку |

Цвета для «Рисунка» выбираются тремя способами: **Группы цветов** (кнопка *Найти цвета* делит
цвета модели на 2–8 групп, отметьте галочками нужные), **Пипетка** (цвета и допуск) или **Авто**
(все группы, заметно отличные от основного цвета). Картинку — например, флаг — вставьте как
плоскость (*File → Import → Images as Planes*): её границы цветов станут линиями.

Галочка **Простые фигуры** у объекта (включена по умолчанию) рисует черты простыми фигурами,
как художник шоу:
- глаз — кольцом (пара глаз — одинаково; большой глаз — со зрачком);
- почти круглая или овальная линия — ровным кругом или эллипсом;
- почти прямой отрезок — прямым;
- круглое тело (шар, тыква, шары снеговика) — кольцами вокруг вертикальной оси снизу вверх, а не
  плоской сеткой.

Заливка **Кольца** ставит кольца на любой объект. Подробности — в `docs/algorithm.md`, раздел 8.3.

### Вокруг (3D): фигура, которую видно со всех сторон

**Область → Вокруг (3D)** — для 3D-фигур, которые зрители видят со всех сторон (или фигура вращается).
Ночью дроны не загораживают друг друга, передние и задние светятся вместе. Точки, рассыпанные ровным слоем
по поверхности, складываются в кашу и комки. Точки на гладких линиях складываются в линии. Поэтому фигура
рисуется линиями, а силуэт остаётся чётким с любой стороны:
- **Круглые тела** (яблоко, тыква, кабачок, мяч, ваза) — каркас из меридианов по рёбрам. У гладкого
  фрукта их 11, у ребристой тыквы — по числу рёбер. Внизу кольцо-донышко. Стебель — трубка из трёх дронов
  своего цвета с воротничком. Вырезанные глаза и рот — яркие жёлто-тёплые контуры с углами вокруг тёмных
  дырок; рёбра за дырками убраны, чтобы лицо читалось и спереди. Плоская макушка остаётся тёмной.
- **Точёные формы** (катушка, ваза, бокал, цилиндр) — по рёбрам профиля идут целые кольца: края, перехваты,
  ступени. Между далёкими рёбрами добавляются промежуточные кольца, меридианы приглушены. Плоский верх и
  низ рисуются только своим краем. Тонкая ножка бокала — столбик из трёх дронов цвета тела.
- **Персонажи и животные** — как в больших шоу (Чунцин): тело заливается ровными рядами (каждое
  горизонтальное сечение, дроны через равный шаг, ряды со сдвигом на полшага), ряды чуть приглушены.
  Поверх ярко: глаза (находятся по картинке спереди, кольцо из 6 дронов с тёмной серединой и тёмным
  зазором вокруг), белые контуры там, где рука прилегает к телу, корона и рамки своего цвета, шарики на
  зубцах. Ночью дроны не заслоняют друг друга, поэтому глаза видны и сзади.
- Тип определяется сам. Несколько выделенных объектов делят бюджет по площади и держат дистанцию между собой.
- «Вершин» — это максимум. Сетка не бывает гуще 1.6 мин. дистанции, поэтому небольшой фрукт может взять
  меньше: так рисунок остаётся читаемым.

### Кривые: упрощённая модель для рисунка

На самой модели линии лежат на разной глубине: контур идёт по бокам, вырезанный глаз сидит глубоко
внутри. Поэтому рисунок складывается только с одной точки. Кнопка **Построить кривые** (рядом с
**Глубиной кривых**) рисует выделенную модель так, как её видят зрители: контур, черты (глаза, нос,
рот с углами), сильные линии, простые фигуры. Получается объект-кривая `<модель>_кривые`:
- одна линия — один сплайн, его цвет — материал `Pointille кривая #rrggbb`;
- сплайн из одной точки — одна вершина;
- скрытая дочерняя гладкая **оболочка** `<модель>_оболочка` — на ней стоит заливка.

Углубления всегда убраны. Глубина выбирается:
- **Плоско** — всё в одной плоскости лицом к зрителям;
- **Неглубоко** — четверть глубины, по умолчанию;
- **По форме** — объём модели;
- **Объём** — вся модель, видна со всех сторон: горизонтальные срезы снизу доверху (приглушённые,
  в цветах модели, материал `Pointille срез #rrggbb`), а прямо на поверхности — контур, глаза, рот и
  сильные линии. Срезы обходят черты и не заходят внутрь вырезанных глаз. Оболочки и заливки нет.

Рисунок берёт только сильные линии: длинные (от 4 шагов) и не слабее пятой части лучшей; шерсть,
морщины и складки в него не попадают. Глаза, вылепленные в цвет лица (глазные яблоки в глазницах),
находятся по рельефу: пара одинаковых бугорков на одном уровне, симметричная относительно середины
головы.

Кривые можно править руками: удалить линию, подвинуть точку, дорисовать свою, поменять цвет
материала. Затем выделите кривые и нажмите **Распределить вершины**. Вершины встанут в углы, вдоль
линий (у углов гуще) и редкой сеткой внутри замкнутых кривых; замкнутая кривая внутри другой — дыра.
Контур из нескольких кусков, концы которых сходятся, тоже получает заливку.
Так же работает любая кривая, нарисованная вручную. Модели и кривые за один раз не распределяются.

Черты объекта — это целые области, которые отличаются цветом или глубиной (вырезанные глаза и рот
тыквы, солнце на флаге). Сразу после силуэта они обводятся замкнутой линией с углами.

Если вершин не хватает, первой реже становится заливка (до 2 раз), и только потом линии.

В режиме **Вся поверхность** (360°) линии рисуются с четырёх сторон, каждая сторона — на своей
части поверхности. Если у шоу есть главная сторона зрителей, самый чистый рисунок даёт режим
**Фасад**.

Вершины в углах собраны в группу `Pointille углы`, на линиях и в углах — в `Pointille обводка`,
при нескольких объектах вершины каждого — в `Pointille: <имя объекта>`; атрибут `pointille_kind`
хранит 0 (угол), 1 (линия) или 2 (заливка). В Skybrush по этим группам можно сделать свои световые
эффекты.

Режим **Ровно** — как раньше: ровно столько вершин равномерно по всей выделенной модели. С галочкой
**Обводка** часть вершин встаёт на линии модели (силуэт, рельеф, рёбра, края, границы цветов) гуще
заливки. Эти вершины отмечены атрибутом `pointille_outline` и собраны в группу вершин
`Pointille обводка` — в Skybrush по ней можно сделать обводке свой световой эффект.

Масштабирование меняет только трансформацию объекта модели (и её родителя), а не сетку и не
текстуры.

### Объект на вершинах

В поле **Объект на вершинах** можно выбрать любой объект — например, модель дрона с точными
размерами, — и он встанет в каждую вершину (модификатор Geometry Nodes `Pointille Instances`,
экземпляры без копирования геометрии). Очистите поле — останутся только вершины.

- Объект ставится своей точкой начала координат (origin), в своём размере и повороте: масштаб
  модели на него не влияет. Где стоит сам объект, неважно — его можно держать в скрытой или
  выключенной коллекции.
- Цвет вершины доступен в материале объекта: узел **Attribute**, тип **Instancer**, имя
  `drone_color`.
- Модель из нескольких частей: соберите части в коллекцию и выберите её экземпляр
  (*Add → Collection Instance*).
- Превратить экземпляры в обычные объекты: *Object → Apply → Make Instances Real*.

Сцены из версии 0.1: после повторного «Распределить вершины» старые светящиеся шары удаляются.

### Цвета дронов в Skybrush Studio

Выделите объект `<модель>_points` в Object Mode, создайте формацию Skybrush (*Formations → +*,
*Initialize with: Selected objects*), поставьте её в раскадровку и пересчитайте переходы. Дроны
встанут на вершины группы `Pointille` — то есть на все.

**Часть вершин.** Чтобы формацию составили не все вершины, сделайте свою группу как обычно:
Edit Mode → выделите вершины → *Vertex Groups → + → Assign* → в *Drone Show* нажмите *Use selected*
(или выберите группу в блоке «Результат» → Skybrush → «Группа вершин формации» — это то же поле).
Pointille вашу группу не трогает: повторное «Распределить вершины» оставляет её в поле и в группе
те же номера вершин, но вершины с этими номерами стоят уже в других местах — после нового
распределения выделите часть заново. Перед созданием формации выйдите из Edit Mode — Skybrush
читает группы из сохранённой сетки. Если поле очистить, следующее «Распределить вершины» снова запишет `Pointille`.

Цвета устроены как **слои**: у каждого слоя свой диапазон
кадров и свой стиль, так что внутри одной формации можно сначала показать текстуру, потом
погасить дронов, потом зажечь их золотом. Блок «Результат» → Skybrush:

1. **Список слоёв** и кнопки: `+` новый слой на весь сегмент (запись раскадровки или переход,
   выбирается в поле «Сегмент», пусто — формация из этих вершин), `−` удалить, стрелки — порядок
   (нижний слой перекрывает верхний там, где диапазоны пересекаются).
2. **Диапазон**: поля «Начало» и «Конец» (кадры) и кнопки с часами — «= текущий кадр». Поставьте
   бегунок на нужный кадр и нажмите **Разрезать по кадру**: слой делится на два, у каждой части
   свои стиль и диапазон. «Плавно зажечь / погасить» и «Влияние» — обычные настройки слоя Skybrush.
3. **Привязка** («К записи») — как «Attach to» в Skybrush: диапазон слоя следует за записью
   раскадровки. **Цвета из** — формация, по вершинам которой слой берёт цвета дронов.
4. **Стиль** слоя:
   - *Цвета текстуры* — дрон горит цветом своей вершины;
   - *Чёрно-белое* — оттенки серого по яркости текстуры (со скоростью — волны глубины);
   - *Переливы текстуры* — яркость точек как в текстуре, а оттенок плывёт по цветовому кругу;
   - *Радуга* — радужные цвета, светлые и тёмные места текстуры сохраняют глубину;
   - *Градиент двух цветов* — фоновые цвета снизу вверх (например, вода), течёт, если задана скорость;
   - *Один цвет* — все дроны одним цветом, например золотым (дышит, если задана скорость);
   - *Погашены* — дроны не светятся; *Доля стиля* приглушает вместо полного гашения.

   *Доля стиля* смешивает стиль с цветами текстуры (0 — только текстура, 1 — только стиль).
   *Скорость* — циклов в секунду (0 — без движения), *Разброс* — сколько циклов по высоте фигуры.
   *Яркость* и *Насыщенность* правят цвета слоя.

Как это устроено:

- Слой — обычный световой эффект Skybrush `Pointille · <название>`: тип *Image*, Output X —
  *Indexed by drones*, пиксель x картинки — дрон x (цвет вершины, которую дрон занимает в формации).
  Без движения картинка в одну строку; со стилем в движении — строка на каждую 1/12 с, эффект
  читает её по времени (Output Y — *Temporal*). Время считается от нулевого кадра, поэтому у
  разрезанного слоя анимация не прыгает. Цвет верен в любом сегменте, в том числе в переходе к
  формации. Слои сохраняются в .blend и попадают в экспорт шоу; они видны в панели LEDs, поверх них
  можно класть свои эффекты Skybrush.
- Когда Skybrush пересчитывает переходы (дроны меняются маркерами) или слой сдвигают, Pointille сам
  обновляет цвета. Повторное «Распределить вершины» сохраняет группы вершин (формацию и привязку
  дронов `Skybrush[Vertex i]`) и тоже обновляет цвета.
- Дроны, которые не стоят на вершинах Pointille, слои не трогают. Там, где не действует ни один
  слой, дроны горят как раньше (свои цвета и другие эффекты Skybrush).

**Видимость.** В режиме «Фасад» у каждой вершины есть атрибут `pointille_visibility`: доля
зрителей, которые её видят (1 — фасад, 0 — скрытая часть). Его можно использовать в Geometry
Nodes или для выделения скрытых вершин.

**Свои цвета.** В Edit Mode объекта `<модель>_points` выделите вершины, выберите цвет в блоке
«Цвет выделенных вершин» и нажмите **Покрасить** — дроны на этих вершинах загорятся этим цветом.
**Вернуть цвета текстуры** возвращает исходные цвета выделенным вершинам (цвета текстуры
хранятся в атрибуте `pointille_texture_color` у объектов, созданных начиная с версии 0.4).

## Параметры

| Параметр | Что делает |
|---|---|
| Количество дронов | Сколько точек поставить. Всегда ровно столько |
| Область | *Вся поверхность* или *Фасад*: гуще там, где модель видят зрители (поверхность повёрнута к ним не больше чем на заданный угол и не закрыта другими частями модели) |
| Где зрители | Спереди / сзади / слева / справа / сверху / из камеры. Камера — точка: лучи сходятся в ней, с перспективой, как в её кадре |
| Ширина зрителей | На сколько градусов зрители растянуты вокруг модели по горизонтали (по умолчанию 60°). Углы и бока, которые видит только часть зрителей, получают дронов реже фасада |
| Скрытые части | Плотность дронов там, где модель не видит никто, в процентах от фасада (по умолчанию 25 %). Фигура остаётся целой, когда модель поворачивается или анимируется; 0 — там дронов нет |
| Цвет | *Средний по участку* (меньше шума на границах текстуры), *точно под дроном* или белый |
| Обводка | Часть дронов ставится точно на линии модели: *силуэт* (контур для зрителей из «Где зрители» и края, где одна часть закрывает другую), *рельеф* (глаза, ноздри, рот, уши, складки — где поверхность изгибается сильнее *изгиба рельефа*, 40°), *рёбра* (изломы круче *угла рёбер*, 40°), *края* открытой поверхности, *цвета* (границы цветов текстуры, порог — *контраст цветов*, 15 %). Силуэт, рельеф и цвета ищутся по картинке модели с точки зрения зрителей. В каждом углу линии — дрон, между углами — через равные расстояния, заливка оставляет линиям место |
| Сколько на обводке | *Плотность*: на линиях во столько раз гуще заливки (по умолчанию ×1.5; дронов — сколько нужно по длине линий, не больше половины). *Доля*: столько процентов всех дронов (по умолчанию 30 %) |
| Мин. яркость | Дрон не светит чёрным: выключенный дрон ночью не виден, и тёмная модель (тёмно-коричневый орёл, чёрные колёса) остаётся с дырами. Самый тёмный дрон горит с этой яркостью, самый яркий — в полную силу; оттенок и порядок яркостей сохраняются, почти чёрное горит ровным тусклым белым. По умолчанию 40 %, 0 — цвета как у модели |
| Масштаб | Не менять / так, чтобы мин. дистанция стала X м / так, чтобы высота фигуры стала X м |
| Seed | Другой вариант такой же ровной расстановки |
| Итерации выравнивания | Сколько шагов «расталкивания» дронов (0 — выключено) |
| Плотность кандидатов | Сколько случайных точек на дрона берётся для отбора (по умолчанию 8) |

Модели от ИИ обычно имеют размер около 1–2 единиц. Перед шоу включите масштаб «под
мин. дистанцию» (например, 1.5–2 м) — фигура вырастет до реального размера.

## Как это работает

Коротко: плотные случайные точки на поверхности → Weighted Sample Elimination (Yuksel, 2015)
оставляет ровно N с максимальным разнесением → несколько итераций взаимного отталкивания с точной
проекцией обратно на поверхность → цвет из текстуры по UV. С обводкой сначала находятся линии
модели, на них встают дроны через равные расстояния, и заливка идёт вокруг них. Подробно: [docs/algorithm.md](docs/algorithm.md).

Алгоритм реализован дважды с одинаковой логикой: `pointille/core` (Python + numpy, работает и
внутри Blender) и `web/core` (JavaScript для браузера).
