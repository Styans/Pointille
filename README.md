# Pointille

Инструмент для создателей дрон-шоу. Загрузите 3D-модель (например, сгенерированную ИИ), укажите
количество дронов — Pointille равномерно расставит ровно столько точек по её поверхности и возьмёт
для каждой цвет текстуры в том месте, где она стоит.

**Исходная модель не изменяется**: сетка, UV, материалы и текстуры остаются как были. Дроны — это
отдельный объект поверх модели.

| | |
|---|---|
| Точное количество | Вы задаёте N — получаете ровно N дронов |
| Равномерно | Blue-noise отбор + выравнивание: минимальная дистанция ≈ 0.8 от идеальной сотовой сетки |
| Цвет из текстуры | Цвет под дроном или средний цвет его участка поверхности |
| Фасад | Только сторона, которую видят зрители (с учётом перекрытий) |
| Безопасность | Показ мин./средней дистанции, масштабирование под мин. дистанцию или высоту фигуры |
| Где работает | Веб-версия (любая ОС, без установки), аддон Blender, командная строка |
| Результат | GLB (модель + дроны), CSV (м, Z вверх), PLY — открываются в Blender, Cinema 4D, Houdini, 3ds Max, Maya, Unreal, Unity, Skybrush |

## Веб-версия

Откройте `web/index.html` через любой локальный сервер:

```bash
npx http-server web -p 8080        # или: python -m http.server -d web 8080
```

и перейдите на <http://localhost:8080>. После включения GitHub Pages (Settings → Pages → Source:
GitHub Actions) страница публикуется автоматически из ветки `main`.

1. Перетащите модель: **GLB** / **GLTF** (+ .bin и текстуры) / **OBJ** (+ .mtl и текстуры) / **FBX**.
   Сжатые Draco и Meshopt GLB поддерживаются.
2. Задайте **количество дронов** — расстановка пересчитывается автоматически.
3. Выберите **область** (вся поверхность / фасад), **цвет** и при необходимости **масштаб**.
4. Скачайте результат:
   - **GLB: модель + дроны** (для GLB на входе) — исходный файл сохранён байт в байт, добавлен узел
     `Pointille_Drones` (точки с цветом `COLOR_0`). Если выбран масштаб, всё помещается под узел
     `Pointille_Root` с нужным масштабом;
   - **CSV** — `id,x,y,z,r,g,b,hex`, метры, Z вверх (как в Blender и большинстве программ для шоу);
   - **PLY** — облако точек с цветами в системе координат модели.

Переключатель «Только дроны» показывает, как фигура будет выглядеть ночью.

## Аддон для Blender

Blender 4.2+ (как Extension) и 3.6–4.1 (как обычный аддон).

```bash
python tools/build_blender_addon.py     # → dist/pointille_blender-0.1.0.zip
```

Blender → *Edit → Preferences → Add-ons → Install from Disk…* → выберите zip (или скачайте
его из артефактов GitHub Actions).

В 3D-виде нажмите **N** → вкладка **Pointille**:

1. Выделите модель (можно несколько мешей — они считаются вместе).
2. Укажите **Дронов**, **Область**, **Цвет**, **Безопасность** → **Распределить дронов**.
   Параметры можно менять после запуска в панели *Adjust Last Operation* (F9) — результат
   пересчитывается.
3. Появятся объекты:
   - `<модель>_drones` — меш **только из вершин** (по одной на дрона) с атрибутом цвета
     `drone_color`. Он привязан к модели и двигается вместе с ней. Этот объект можно сразу
     использовать в Skybrush Studio как формацию из вершин;
   - `<модель>_drones_preview` — светящиеся шары цвета дронов (Geometry Nodes), только для
     просмотра; включается и выключается переключателем «Светящиеся шары».
4. В блоке «Результат»: мин. и средняя дистанция, габариты, кнопки **Масштабировать** и
   **Экспорт CSV**.

Масштабирование меняет только трансформацию объекта модели (и её родителя), а не сетку и не
текстуры.

## Командная строка

```bash
pip install ".[cli]"
pointille model.glb -n 800                               # вся поверхность
pointille model.glb -n 800 --facade --view front         # только фасад
pointille model.glb -n 800 --min-dist 1.5 -o out/        # масштаб под дистанцию 1.5 м
pointille model.obj -n 300 --color point --height 40     # OBJ, высота фигуры 40 м
```

Выход: `<имя>_pointille.glb` (для GLB) или `<имя>_drones.glb`, плюс `<имя>_drones.csv` и
`<имя>_drones.ply`. `pointille --help` — все параметры. Сжатые Draco GLB распакуйте заранее:
`npx @gltf-transform/cli decompress in.glb out.glb` (или используйте веб-версию).

## Параметры

| Параметр | Что делает |
|---|---|
| Количество дронов | Сколько точек поставить. Всегда ровно столько |
| Область | *Вся поверхность* или *Фасад* — только поверхности, повёрнутые к зрителю не больше чем на заданный угол и не закрытые другими частями модели |
| Где зрители | Спереди / сзади / слева / справа / сверху / по текущей камере |
| Цвет | *Средний по участку* (меньше шума на границах текстуры), *точно под дроном* или белый |
| Масштаб | Не менять / так, чтобы мин. дистанция стала X м / так, чтобы высота фигуры стала X м |
| Seed | Другой вариант такой же ровной расстановки |
| Итерации выравнивания | Сколько шагов «расталкивания» дронов (0 — выключено) |
| Плотность кандидатов | Сколько случайных точек на дрона берётся для отбора (по умолчанию 8) |

Модели от ИИ обычно имеют размер около 1–2 единиц. Перед шоу включите масштаб «под
мин. дистанцию» (например, 1.5–2 м) — фигура вырастет до реального размера.

## Как это работает

Коротко: плотные случайные точки на поверхности → Weighted Sample Elimination (Yuksel, 2015)
оставляет ровно N с максимальным разнесением → несколько итераций взаимного отталкивания с точной
проекцией обратно на поверхность → цвет из текстуры по UV. Подробно: [docs/algorithm.md](docs/algorithm.md).

Алгоритм реализован дважды с одинаковой логикой: `pointille/core` (Python + numpy, работает и
внутри Blender) и `web/core` (JavaScript для браузера).

```bash
pip install -e ".[test]"
```
